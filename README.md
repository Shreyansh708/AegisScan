# AegisScan

An ESP32-based intelligent scanning radar prototype developed as an embedded systems project.

---

## Features

- 🎮 Manual joystick-controlled radar
- 🔄 Automatic radar sweep mode
- 🔘 Push-button mode switching
- 📏 HC-SR04 ultrasonic distance measurement
- 📺 SSD1306 OLED display
- 🚦 Green, Yellow and Red threat indication LEDs
- 🔊 Buzzer warning system

---

## Hardware Used

- ESP32 Development Board
- SG90 Servo Motor
- HC-SR04 Ultrasonic Sensor
- SSD1306 OLED Display
- Joystick Module
- Push Button
- Active Buzzer
- LEDs
- Breadboard & Jumper Wires

---

## Pin Configuration

| Component | GPIO |
|-----------|------|
| Servo | 18 |
| Joystick | 34 |
| Push Button | 33 |
| Ultrasonic Trigger | 5 |
| Ultrasonic Echo | 17 |
| Green LED | 25 |
| Yellow LED | 26 |
| Red LED | 27 |
| Buzzer | 14 |
| OLED SDA | 21 |
| OLED SCL | 22 |
